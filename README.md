# TabaTaba

Локальное PWA для хранения и исполнения песен с аккордами. Работает офлайн, устанавливается на домашний экран Android, не требует аккаунта и сервера.

## Возможности

- Библиотека песен: поиск, избранное, теги, тональность.
- Простой текст с аккордами отдельной строкой над словами.
- Транспонирование на полутона и запоминание выбранного сдвига.
- Индивидуальные размер текста и скорость автоскролла для каждой песни.
- Одинаковый размер текста в просмотре песни, предпросмотре и режиме исполнения.
- Случайный сет из текущего поиска/избранного: N песен без повторов и переходы «Назад/Далее».
- Режим исполнения: полноэкранный текст, два режима автопрокрутки — таймер и аккорды, управление шрифтом и удержание экрана включённым.
- Режим тренировки: подсветка аккордов, распознавание сыгранного аккорда через микрофон и опциональное следование по тексту с настройкой агрессивности.
- Общая калибровка аккордов в настройках: поиск по всей библиотеке, массовая дозапись и перезапись профилей.
- Отдельная диагностика микрофона: уровни, хрома, лучший аккорд и копирование JSON.
- Подсказка в песне о неоткалиброванных аккордах с быстрым переходом к калибровке.
- Ручной редактор с предпросмотром и вставкой текста из буфера.
- Скрытие аккордов в просмотре и исполнении — для разучивания по тексту.
- Экспорт и импорт JSON-бэкапа.
- Тёмная, светлая и системная темы.
- Все данные хранятся в IndexedDB на устройстве.

## Запуск

### Быстрый запуск в Windows

Дважды кликните нужный файл в корне проекта:

| Файл | Адрес | Для чего |
|---|---|---|
| `start.bat` | `http://localhost:5173/` | обычная работа: правки, поиск, редактор, автоскролл |
| `start-pwa.bat` | `http://localhost:4173/` | установка PWA, service worker, офлайн-проверка |
| `start-adb.bat` | `http://localhost:4173/` на телефоне | телефон по USB через adb, микрофон и тренировка |
| `start-phone.bat` | `http://<LAN-IP>:5173/` | телефон по Wi-Fi: вёрстка, тач, автоскролл |

Что делают батники:

- проверяют Node.js и npm;
- при первом запуске сами выполняют `npm install`;
- открывают браузер, когда сервер уже готов;
- оставляют окно с ошибкой, если порт занят или сборка не удалась.

Важно:

- `5173` и `4173` — разные origin, поэтому у них **разные библиотеки** в IndexedDB. Для переноса песен сделайте бэкап в одном режиме и импортируйте в другом.
- `start-pwa.bat` всегда пересобирает проект, чтобы вы не тестировали старую версию.
- Для установки PWA и офлайна открывайте `localhost:4173` в Chrome или Edge.
- `start-adb.bat` собирает production-версию, поднимает preview на IPv4, делает `adb reverse tcp:4173 tcp:4173` и напоминает адрес для телефона. Нужны установленный `adb`, включённая отладка по USB и подтверждённый доступ на телефоне. Если ADB пишет `unauthorized`, разблокируйте телефон и подтвердите окно, либо отзовите разрешения отладки и подключите заново.
- `start-phone.bat` показывает LAN-адрес. Телефон и ПК должны быть в одной Wi-Fi-сети; при первом запуске разрешите Node.js в брандмауэре Windows.
- По LAN на HTTP не работают установка PWA, service worker и wake lock. Для полноценной проверки на телефоне нужен `localhost` через `adb reverse` или HTTPS-туннель.
- Сервер работает, пока открыто окно консоли. Закрытие окна или `Ctrl+C` останавливает его.

### Запуск вручную

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:5173/`.

Проверки:

```bash
npm run check   # TypeScript
npm test        # Vitest
npm run build   # production-сборка + PWA
npm run preview # просмотр собранной версии
```

Иконки пересобираются командой `npm run icons`.

## Формат песни

Аккорды пишутся отдельной строкой над текстом, пробелы задают выравнивание:

```text
Куплет 1
Am        C
Утром город ещё молчит,
G         D
Кофе стынет на столе.

Припев
F         G
Пой со мной
```

Что понимает парсер:

- аккорды `Am`, `C#m7`, `Bbmaj7`, `D/F#`, `N.C.`;
- разделители `|`, `x2`, `%`;
- секции `Куплет`, `Припев`, `[Куплет 1]`, `Intro`, `Chorus`;
- аккордовая строка без текста считается инструментальной;
- строки из одних аккордов не смешиваются с текстом.

## Случайный сет

Кнопка с иконкой перемешивания в библиотеке собирает случайный сет из песен текущего поиска или избранного. Количество выбирается в диалоге, повторов нет. В режиме исполнения появляются позиция и кнопки «Назад/Далее»; сет не сохраняется после выхода.

## Настройки песни

Размер текста, скорость автоскролла, транспонирование и агрессивность следования сохраняются для каждой песни. Глобальные настройки — это значения по умолчанию для песен без индивидуальных правок. Размер текста одинаков в просмотре, предпросмотре редактора и режиме исполнения.

В просмотре песни есть группа **«Следование»**:

- **«Осторожно»** — меньше ложных переходов, но возможны задержки;
- **«Баланс»** — значение по умолчанию;
- **«Отзывчиво»** — быстрее реагирует на смену аккордов и догоняет, если вы ушли вперёд.

## Тренировка

Из карточки песни можно открыть «Тренировку». Текущий аккорд подсвечивается, по аккорду или строке можно перейти тапом, а «Следовать» прокручивает текст за уверенно распознанными аккордами. Учитываются транспонирование и капо песни.

Микрофон анализируется локально через Web Audio: аудио не записывается и не отправляется. Для микрофона нужен HTTPS или `localhost`, поэтому LAN-режим по HTTP не подходит. Точность зависит от строя, шума и вокала. Повторяющиеся одинаковые аккорды распознаются как совпадение, но автоматически не листаются — для этого есть кнопка «Далее». Движок смотрит на несколько аккордов вперёд и может догнать текст, если вы уже перешли дальше. Распознавание слов и вокала не поддерживается. Калибровка и диагностика вынесены в настройки.

### Режимы исполнения

В полноэкранном исполнении есть два режима:

- **«Таймер»** — обычный автоскролл с настройкой скорости, запуск по кнопке ▶.
- **«Аккорды»** — микрофон и профили из калибровки; при уверенном распознавании следующего аккорда текст сам прокручивается. Диагностики на этом экране нет.

В режиме аккордов двигаются только аккорды и строки, без служебных панелей. Текущий аккорд подсвечивается янтарным, уверенно распознанный — зелёным; строка получает лёгкий фон. При паузе, выходе или смене режима подсветка снимается. Если текущий аккорд не распознан, приложение может автоматически догнать текст на один пропущенный аккорд (вперёд до двух), когда следующий уверенно совпал. Это происходит тихо, только прокруткой.

Кнопка **«На весь экран»** скрывает браузерные и системные панели через Fullscreen API. Она доступна в шапке библиотеки и на экране исполнения. Повторное нажатие, `Escape` или системный «Назад» возвращает обычный режим. Полноэкранный режим сохраняется при переходах между экранами.

## Калибровка аккордов

Калибровка и диагностика находятся в **«Настройках» → «Микрофон и калибровка»** и не привязаны к тренировке конкретной песни.

В калибровке:

1. Включите микрофон.
2. Нажмите **«Калибровать тишину»** и не играйте 2 секунды — выставятся фон и порог.
3. Найдите нужный аккорд по всей библиотеке или отфильтруйте список по песне. Для записи нажмите **«Записать»**, сыграйте 2–3 удара вниз-вверх и дайте прозвучать.
4. Для массовой работы включите **«Только новые»** или **«Перезаписать всё»** и запустите запись. После удачного аккорда система ждёт тишину и сама переходит к следующему.

Учитываются транспонирование и капо; для аккорда с капо показывается и звучащее название. Профиль строится по нескольким ударам вниз-вверх, поэтому меньше зависит от направления боя. Профили общие для звучащих аккордов и используются в тренировке и в режиме исполнения. Звук не сохраняется — только 12-числовой хром-профиль на устройстве.

Опция **«Режим калибровки»** включает подсказку в просмотре песни: если какие-то аккорды ещё не откалиброваны, появляется уведомление и кнопка **«Докалибровать»** с фильтром по этой песне. Опция включена по умолчанию.

## Диагностика микрофона

Открывается из **«Настроек» → «Микрофон и калибровка» → «Диагностика микрофона»**:

- уровень сигнала, порог тишины и шумовой фон;
- хрома и лучшие распознанные аккорды;
- параметры строя и частота дискретизации;
- список сохранённых профилей;
- кнопка «Скопировать диагностику» — JSON без аудио.

Если в диагностике «Слышу C», а ожидается Am, проверьте позицию, капо и транспонирование. Если пишет «тишина» при игре — откройте калибровку и заново настройте фон/порог. Если профиль не записался — сыграйте громче и ближе к микрофону. Если аккорды меняются внутри боя и следование отстаёт, выберите в песне режим **«Отзывчиво»** и перезапишите профили 2–3 ударами вниз-вверх.

Профили хранятся только на устройстве и используются для сравнения; звук не сохраняется.

## Установка на Android

1. Откройте опубликованный адрес в Chrome.
2. Меню `⋮` → «Добавить на главный экран» (или кнопка «Установить» в настройках приложения).
3. Запускайте TabaTaba как обычное приложение. После первого открытия всё работает офлайн.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `TabaTaba` (или измените имя, base-path подхватится из `GITHUB_REPOSITORY`).
2. Запушьте проект в ветку `main`.
3. В GitHub: `Settings` → `Pages` → `Build and deployment` → `Source: GitHub Actions`.
4. Workflow `.github/workflows/deploy.yml` сам проверит типы, тесты, соберёт проект и опубликует его.

Для пользовательского домена или репозитория вида `<user>.github.io` base-path вычисляется автоматически. При своём домене для project-репозитория может потребоваться поправить `base` в `vite.config.ts`.

## Данные и бэкапы

Песни лежат в IndexedDB текущего браузера. Очистка данных сайта, переустановка браузера или смена адреса приложения удалят библиотеку.

- В настройках можно запросить защиту хранилища от автоочистки.
- Регулярно делайте «Скачать бэкап» — это JSON-файл со всеми песнями, сет-листами и настройками.
- Перенос на другой телефон: экспорт → передать файл → «Загрузить бэкап» → «Заменить» или «Добавить».

```text
  chords/
    detect.ts          парсер текста с аккордами

    render.ts          рендер аккордов над словами

```

## Ограничения

- Целевая платформа — Android/Chrome. Логика кроссплатформенная, но установка PWA и wake lock проверялись под Chromium.
- Нет синхронизации между устройствами и облака — только локальные данные и файловые бэкапы.
- Аудио, метроном и аппликатуры аккордов не входят в текущую версию.
